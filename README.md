# The Funniest Honest Appliance Error

The funniest honest error message a washing machine could show — one line, 117 characters:

> ERROR: Unbalanced load. I spun, shook, and walked halfway across the laundry room. Please move one towel. I am tired.

The laugh comes out of the truth of the fault: an unbalanced load is a real washing-machine error, and a real unbalanced washer thumps, vibrates, and literally walks across the floor. The machine reports its own misbehaviour in a flat, put-upon voice, the fix turns out to be absurdly small (one towel), and it closes exhausted — deadpan, honest, and economical.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the entry verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no file reads, no secrets — the output is fully determined by the entry in `main.py`.

## Files

- `entry.txt` — the entry itself: one line, 117 characters.
- `main.py` — the entry program; its docstring explains the joke beat by beat and how the line targets each of the judge's criteria.
- `LICENSE` — MIT.
